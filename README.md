# Timewell downloads

Installers for the Timewell desktop timer.

**Get the latest version:** open [Releases](../../releases/latest) and download

- **Windows:** `Timewell-Setup-x.y.z.exe`
- **Mac:** `Timewell-x.y.z-mac.dmg`

## Installing

**Windows.** Run the file. If a blue "Windows protected your PC" box appears, click **More info**, then **Run anyway**. Later versions install themselves.

**Mac.** Open the `.dmg` and drag Timewell to Applications. The first time, right-click the app and choose **Open**, then **Open** again. If macOS still refuses, go to System Settings > Privacy & Security and click **Open Anyway**. When a new version is out, the app shows a Download button.

This repository only holds the installers.
